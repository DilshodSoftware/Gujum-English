47-DARS. OBJECT PRONOUNS

Me / You / Him / Her / It / Us / Them · Object olmoshlari
Subject pronouns (I, he, she...) ishni bajaruvchini bildiradi. Object pronouns esa harakat kimga yoki nimaga qaratilganini bildiradi.

1. Subject va Object farqi

Oddiy gapda avval ishni bajaruvchi, keyin fe’l keladi. Fe’ldan keyin esa harakat qaratilgan object kelishi mumkin.

Subject + Verb + Object
I know Ali.Men Alini taniyman.
Ali helps me.Ali menga yordam beradi.

Birinchi gapda I ishni bajaryapti — subject. Ikkinchi gapda me yordam olayotgan odam — object.

2. Yetti Object Pronoun

Subject — egaObject — to‘ldiruvchiO‘zbekcha

You va it subject va object holatida bir xil yoziladi. Boshqa ayrim olmoshlar o‘zgaradi: I → me, he → him, they → them.

3. Object pronoun fe’ldan keyin keladi

She likes me.U meni yoqtiradi.
I see him.Men uni ko‘ryapman. (erkak)
We help her.Biz unga yordam beramiz. (ayol)
They know us.Ular bizni taniydi.
Tom calls them.Tom ularga qo‘ng‘iroq qiladi.

4. Object pronoun predlogdan keyin ham keladi

Ingliz tilida to, with, for kabi kichik so‘zlardan keyin ham object pronoun ishlatiladi.

Come with me.Men bilan kel.
This is for you.Bu siz uchun.
Give it to him.Uni unga ber.
She sits next to us.U bizning yonimizda o‘tiradi.

5. Ismni Object Pronoun bilan almashtiramiz

I see Ali. → I see him.Men Alini ko‘ryapman. → Men uni ko‘ryapman.
We know Sara. → We know her.Biz Sarani taniymiz. → Biz uni taniymiz.
He likes the dog. → He likes it.U itni yoqtiradi. → U uni yoqtiradi.
The teacher helps the students. → The teacher helps them.O‘qituvchi o‘quvchilarga yordam beradi. → O‘qituvchi ularga yordam beradi.

6. Her: Object Pronoun yoki Possessive Adjective?

Her ikki vazifada kelishi mumkin. Gapdagi o‘rniga qarab farqlaymiz.

I see her.Men uni ko‘ryapman. (her = object pronoun)
I see her bag.Men uning sumkasini ko‘ryapman. (her + noun = possessive adjective)
Her dan keyin ot kelsa, ko‘pincha “uning” ma’nosidagi egalik so‘zi bo‘ladi: her book. Ot bo‘lmay, harakat qaratilgan odam bo‘lsa, object pronoun: I know her.

7. Ko‘p uchraydigan xatolar

He likes me. ✅
Him likes I. ❌

I see her. ✅
I see she. ❌

They help us. ✅
They help we. ❌

This is for him. ✅
This is for he. ❌

Mashq 1 — Mos Object Pronounni tanlang

1. I know Ali. I know (he / him).

2. She helps (I / me).

3. We see the girls. We see (they / them).

4. Come with (we / us).

5. The dog follows (she / her).

6. This gift is for (you / your).

Javoblar:
1. him. 2. me. 3. them. 4. us. 5. her. 6. you.

Mashq 2 — Ismni olmosh bilan almashtiring

1. I call Sara. → I call ___.

2. Ali sees the cat. → Ali sees ___.

3. We visit our friends. → We visit ___.

4. The teacher helps you and me. → The teacher helps ___.

Javoblar:
1. her. 2. it. 3. them. 4. us.
