Bir oz / bir nechta · Miqdori aniq bo‘lmaganda

Some va any miqdor aniq bo‘lmaganda ishlatiladi. Ikkalasi ham sanaladigan ko‘plikdagi otlar bilan ham, sanalmaydigan otlar bilan ham kelishi mumkin.

1. Some — darak gaplarda

Some ko‘pincha darak gapda “bir nechta” yoki “bir oz” ma’nosini beradi.

I have some apples.Menda bir nechta olma bor.
We have some books.Bizda bir nechta kitob bor.
There is some water.Biroz suv bor.
She wants some rice.U biroz guruch xohlaydi.

2. Some bilan qaysi otlar keladi?

Some dan keyin bitta sanaladigan ot odatda kelmaydi: some apple demaymiz. Bitta olma bo‘lsa an apple, bir nechta bo‘lsa some apples deymiz.

3. Any — inkor gaplarda

Inkor gapda, ya’ni “... yo‘q” deganda ko‘pincha any ishlatiladi.

I don’t have any apples.Menda olma yo‘q.
They don’t have any books.Ularda kitob yo‘q.
There isn’t any water.Suv yo‘q.
He doesn’t have any money.Unda pul yo‘q.

4. Any — ko‘p savollarda

Biror narsa bormi yoki yo‘qmi, bilmasak, savolda ko‘pincha any ishlatamiz.

Do you have any brothers?Aka-ukalaringiz bormi?
Does she have any questions?Uning savollari bormi?
Is there any milk?Sut bormi?
Are there any chairs?Stullar bormi?

6. Taklif va iltimosda Some

Taklif qilganda yoki muloyim iltimos bildirganda savolda some ishlatilishi mumkin.

Would you like some tea?Biroz choy xohlaysizmi?
Can I have some water, please?Iltimos, biroz suv olsam bo‘ladimi?

Would you like ...? — muloyim taklif qilish uchun ko‘p ishlatiladigan tayyor ibora. Hozircha uni butunicha yodlab oling: Would you like some tea?

Boshlang‘ich asosiy qoida: darak gapda some, inkor va oddiy savolda any. Taklif/iltimos kabi ayrim savollarda some ham ishlatiladi.
