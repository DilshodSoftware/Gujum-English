38-AMALIYOT. THERE IS / THERE ARE

Joyda bor · darak · inkor · savol · qisqa javob
There is — bitta yoki sanalmaydigan narsa bor. There are — bir nechta narsa bor. Inkor uchun isn’t/aren’t, savolda is/are gap boshiga chiqadi.

1-mashq — Is yoki Are?

1. There ___ a lamp on the desk.

2. There ___ two windows in the room.

3. There ___ some water in the bottle.

4. ___ there a bank near here?

5. ___ there any students in the classroom?

Javoblar: 1. is; 2. are; 3. is; 4. Is; 5. Are.

2-mashq — Darak gapni inkor qiling

1. There is a cat in the garden.

2. There are chairs in the kitchen.

3. There is milk in the fridge.

4. There are two parks near my house.

Javoblar:
1. There isn’t a cat in the garden. 2. There aren’t chairs in the kitchen.
3. There isn’t milk in the fridge. 4. There aren’t two parks near my house.

3-mashq — Savol shakliga o‘tkazing

1. There is a library near here.

2. There are three apples in the bag.

3. There is any juice in the glass. (savol)

Javoblar: 1. Is there a library near here? 2. Are there three apples in the bag? 3. Is there any juice in the glass?

4-mashq — Qisqa javobni to‘ldiring

1. Is there a bus stop nearby? (ha) — Yes, there ___.

2. Are there any eggs? (yo‘q) — No, there ___.

3. Is there water in the jug? (yo‘q) — No, there ___.

Javoblar: 1. is; 2. aren’t; 3. isn’t.

5-mashq — There is/are yoki It is?

1. ___ a book on the table. (kitob bor)

2. ___ my book. (u mening kitobim)

3. ___ two dogs in the yard. (itlar bor)

4. ___ very small. (mushuk juda kichkina)

Javoblar: 1. There is; 2. It is; 3. There are; 4. It is.

6-mashq — Rasmli vaziyatni gap bilan tasvirlang

Xonada bitta stol, ikkita stul va suv yo‘q. Inglizcha 3 ta gap tuzing.

Namunaviy javob: There is a table in the room. There are two chairs. There isn’t any water.
