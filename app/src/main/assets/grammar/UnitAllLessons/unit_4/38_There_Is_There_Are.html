38-DARS. THERE IS / THERE ARE

Biror joyda narsa yoki odam borligini aytish
There is / There are biror joyda narsa yoki odam borligini aytish uchun ishlatiladi. Qaysi shaklni tanlashimiz narsaning bitta yoki ko‘p ekaniga bog‘liq.

1. There is — bitta narsa bor

Bitta sanaladigan narsa yoki odam haqida gapirganda There is ishlatamiz. Ko‘pincha undan keyin a/an keladi.

There is + a/an + birlikdagi ot
There is a book on the table.Stol ustida bitta kitob bor.
There is an apple in the bag.Sumkada bitta olma bor.
There is a student in the room.Xonada bitta o‘quvchi bor.

2. There are — bir nechta narsa bor

Ikki yoki undan ko‘p narsa yoki odam haqida gapirganda There are ishlatamiz. Ot odatda ko‘plikda bo‘ladi.

There are + ko‘plikdagi ot
There are two books on the table.Stol ustida ikkita kitob bor.
There are three apples in the bag.Sumkada uchta olma bor.
There are students in the room.Xonada o‘quvchilar bor.
There is a chair. ✅ (bitta)
There are chairs. ✅ (bir nechta)
There is chairs. ❌

3. Sanalmaydigan ot bilan There is

Suv, sut yoki guruch kabi umumiy sanalmaydigan otlar bilan odatda There is ishlatiladi.

There is water in the glass.Stakanda suv bor.
There is milk in the fridge.Muzlatkichda sut bor.
There is rice on the plate.Likopchada guruch bor.

4. Inkor: There isn’t / There aren’t

Biror narsa yo‘qligini aytish uchun is yoki are dan keyin not qo‘yamiz.

There isn’t a book on the desk.Parta ustida kitob yo‘q.
There aren’t any chairs in the room.Xonada stullar yo‘q.
There isn’t any milk.Sut yo‘q.

Is not → isn’t, are not → aren’t. Any so‘zini keyingi darslarda batafsil o‘rganamiz.

5. Savol: Is there? / Are there?

Savol tuzishda is yoki are gap boshiga chiqadi.

Is there + bitta narsa?

Are there + ko‘plikdagi narsalar?
Is there a bank near here?Yaqin atrofda bank bormi?
Are there two windows in the room?Xonada ikkita deraza bormi?
Is there water in the bottle?Shishada suv bormi?

6. Qisqa javoblar

Is there a shop nearby?Yes, there is. / No, there isn’t.
Are there any apples?Yes, there are. / No, there aren’t.

7. There is va It is farqi

There is yangi ma’lumot sifatida “biror joyda bor” deydi. It is esa allaqachon bilgan narsamiz haqida “u shu” yoki “u qanday” deb gapiradi.

There is a book on the table.Stol ustida kitob bor. (kitob borligini aytyapmiz)
It is my book.U mening kitobim. (qaysi kitobligini aytyapmiz)

Ko‘p uchraydigan xatolar

There are a book. ❌ → There is a book. ✅
There is two chairs. ❌ → There are two chairs. ✅
Is there books? ❌ → Are there books? ✅

Mashq 1 — Is yoki Are?

1. There ___ a pen on the desk.

2. There ___ three students here.

3. There ___ milk in the cup.

4. ___ there a park near your home?

5. ___ there two doors in the room?

Javoblar:
1. is. 2. are. 3. is. 4. Is. 5. Are.

Mashq 2 — Darak gapni savolga aylantiring

1. There is a library near here.

2. There are four chairs in the room.

3. There is water in the bottle.

Javoblar:
1. Is there a library near here?
2. Are there four chairs in the room?
3. Is there water in the bottle?
