41-AMALIYOT. IMPERATIVES

Buyruq · iltimos · inkor ko‘rsatma
Buyruq: fe’lning oddiy shakli bilan boshlanadi; odatda you aytilmaydi: Open the book. Muloyimlik uchun please qo‘shing. Inkor buyruq: Don’t + oddiy fe’l.

1-mashq — Buyruqni fe’l bilan boshlang

1. ___ the door, please. (open)

2. ___ down. (sit)

3. ___ carefully. (listen)

4. ___ your name here. (write)

5. ___ at the board. (look)

Javoblar: 1. Open; 2. Sit; 3. Listen; 4. Write; 5. Look.

2-mashq — Iltimosni tuzing

1. (please / help me)

2. (close the window / please)

3. (please / repeat the word)

4. (come here / please)

Namunaviy javoblar: 1. Please help me. 2. Close the window, please. 3. Please repeat the word. 4. Come here, please.

3-mashq — Don’t bilan inkor buyruq qiling

1. run → ___

2. open the door → ___

3. touch the screen → ___

4. be late → ___

5. sit here → ___

Javoblar: 1. Don’t run. 2. Don’t open the door. 3. Don’t touch the screen. 4. Don’t be late. 5. Don’t sit here.

4-mashq — Buyruqmi, darakmi?

1. Please stand up.

2. You stand up every morning.

3. Don’t talk.

4. She reads the sentence.

Javoblar: Buyruq/iltimos: 1, 3. Darak gap: 2, 4.

5-mashq — Xatoni tuzating

1. You open the book! (buyruq ma’nosida)

2. Don’t to run.

3. Please you sit down.

4. Don’t touches the picture.

Javoblar: 1. Open the book! 2. Don’t run. 3. Please sit down. 4. Don’t touch the picture.

6-mashq — Sinfdoshga ko‘rsatma bering

Inglizcha ayting: “Kitobni oching”, “Iltimos, o‘qing”, “Shoshilmang”, “Derazani yopmang”.

Namunaviy javoblar: Open the book. Please read. Don’t hurry. Don’t close the window.
