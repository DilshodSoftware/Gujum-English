45-AMALIYOT. SOME / ANY

Darak · inkor · savol · taklif va iltimos
Odatdagi qoida: darak gapda some; inkor va betaraf savolda any. Ikkalasi ham ko‘plikdagi sanaladigan va sanalmaydigan ot bilan keladi. Taklif yoki iltimosda savol bo‘lsa ham some ishlatilishi mumkin.

1-mashq — Some yoki Any?

1. There are ___ apples in the bowl.

2. I don’t have ___ brothers.

3. Is there ___ milk?

4. She has ___ books in her bag.

5. We need ___ bread.

6. They don’t have ___ water.

Javoblar: 1. some; 2. any; 3. any; 4. some; 5. some; 6. any.

2-mashq — Savol turini aniqlang va tanlang

1. ___ you have ___ questions? (betaraf savol)

2. Would you like ___ tea? (taklif)

3. Can I have ___ water, please? (iltimos)

4. Are there ___ chairs? (oddiy savol)

Javoblar: 1. Do, any; 2. some; 3. some; 4. any.

3-mashq — So‘zlarni sanaladigan/sanalmaydigan ot bilan ishlating

1. ___ oranges (ko‘plikdagi sanaladigan)

2. ___ juice (sanalmaydigan)

3. ___ students (ko‘plikdagi sanaladigan)

4. ___ rice (sanalmaydigan)

Javoblar: Har biriga some yoki any kontekstga qarab kelishi mumkin: some oranges/any oranges; some juice/any juice; some students/any students; some rice/any rice.

4-mashq — Xatoni tuzating

1. I don’t have some money.

2. Does she have some sisters? (oddiy, betaraf savol)

3. There is any juice in the glass. (darak)

4. Would you like any coffee? (taklif)

Javoblar: 1. I don’t have any money. 2. Does she have any sisters? 3. There is some juice in the glass. 4. Would you like some coffee?

5-mashq — Some, Any yoki artiklsizmi?

1. I like ___ dogs. (umuman itlarni yoqtiraman)

2. I have ___ dogs. (bir nechta itim bor)

3. I don’t have ___ dog. (hech qanday itim yo‘q)

4. ___ water is important. (suv umumiy ma’noda)

Javoblar: 1. artiklsiz; 2. some; 3. any; 4. artiklsiz.

6-mashq — Qisqa dialogni yakunlang

A: Do you have ___ apples?

B: Yes, I have ___ apples. Would you like ___?

A: Yes, please. Can I have ___ water too?

Javoblar: any, some, some, some.
