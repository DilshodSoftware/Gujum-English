46-AMALIYOT. MUCH / MANY / A LOT OF

How much? · How many? · “Ko‘p” miqdorini aytish
Many sanaladigan ko‘plikdagi otlar bilan; much sanalmaydigan otlar bilan. A lot of ikkalasi bilan keladi. How many/much savollarida ot turini tekshiring.

1-mashq — Many yoki Much?

1. How ___ people are there?

2. How ___ coffee do you drink?

3. We don’t have ___ time.

4. How ___ bags does she have?

5. There isn’t ___ sugar in the jar.

6. How ___ money do they need?

Javoblar: 1. many; 2. much; 3. much; 4. many; 5. much; 6. much.

2-mashq — A lot of bilan gapni to‘ldiring

1. We have ___ books. (ko‘p kitob)

2. He drinks ___ water.

3. They have ___ friends.

4. There is ___ traffic today.

Javoblar: 1–4. a lot of.

3-mashq — Gap turiga mosini tanlang

1. Savolda “nechta olma?” (How many / How much)

2. Inkor gapda “ko‘p vaqt yo‘q” (much / many)

3. Darak gapda “ko‘p do‘stim bor” (a lot of / much)

4. “Qancha sut?” (How many / How much)

Javoblar: 1. How many; 2. much; 3. a lot of; 4. How much.

4-mashq — So‘zlarni tartiblang

1. many / how / books / do / you / have / ?

2. much / how / water / is / there / ?

3. has / a lot of / my brother / toys

Javoblar: 1. How many books do you have? 2. How much water is there? 3. My brother has a lot of toys.

5-mashq — Xatoni tuzating

1. How much chairs are there?

2. She has many water.

3. I have a lot friends.

4. How many money do you need?

Javoblar: 1. How many chairs are there? 2. She has a lot of water. 3. I have a lot of friends. 4. How much money do you need?

6-mashq — A lot of bilan 2 ta gap tuzing

1. Sanaladigan ko‘plikdagi ot bilan: ______

2. Sanalmaydigan ot bilan: ______

Namunaviy javoblar: I have a lot of books. There is a lot of water.
