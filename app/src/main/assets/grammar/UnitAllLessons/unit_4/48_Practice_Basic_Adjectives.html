48-AMALIYOT. BASIC ADJECTIVES

Sifat ma’nosi · ot oldida · to be dan keyin · sifat o‘zgarmaydi
Sifat “qanday?” degan savolga javob beradi. Ot oldida: a red car. To be dan keyin: The car is red. Sifat ko‘plikda ham -s olmaydi: red cars.

1-mashq — Qarama-qarshi ma’noni toping

1. big ↔ ___   2. hot ↔ ___   3. good ↔ ___

4. happy ↔ ___   5. clean ↔ ___   6. fast ↔ ___

Javoblar: 1. small; 2. cold; 3. bad; 4. sad; 5. dirty; 6. slow.

2-mashq — Ot oldiga sifat qo‘ying

1. a ___ house (big)

2. a ___ apple (green)

3. an ___ car (old)

4. a ___ child (happy)

5. ___ shoes (clean, ko‘plik)

Javoblar: 1. a big house; 2. a green apple; 3. an old car; 4. a happy child; 5. clean shoes.

3-mashq — Am, Is yoki Are + sifat

1. I ___ tired.

2. My brothers ___ tall.

3. The soup ___ hot.

4. You ___ very kind.

5. This room ___ clean.

Javoblar: 1. am; 2. are; 3. is; 4. are; 5. is.

4-mashq — Sifat ko‘plikda o‘zgaradimi?

1. one small cat → two ___ cats (small / smalls)

2. a red apple → red ___ (apples / apple)

3. The houses are (big / bigs).

4. They have (new / news) books.

Javoblar: 1. small; 2. apples; 3. big; 4. new.

5-mashq — So‘z tartibini tuzating

1. a / dog / black

2. is / the weather / cold

3. cars / fast / are / these

4. an / old / house

Javoblar: 1. a black dog; 2. The weather is cold. 3. These cars are fast. 4. an old house.

6-mashq — Sifatning ma’nosini kontekstdan toping

1. an old man — old nimani bildiradi?

2. an old phone — old nimani bildiradi?

3. a long road — long nimani bildiradi?

4. a difficult test — difficult nimani bildiradi?

Javoblar: 1. yoshi katta/keksa; 2. eski; 3. uzun; 4. qiyin.
