67-AMALIYOT. NUMBERS 1-100

0-20 yodlash · -teen / -ty farqi · 21-99 yasash · gaplarda qo‘llash
Avval eslang: 11 — eleven, 12 — twelve, 13-19 — -teen, 20,30...90 — -ty. 21-99: o‘nlik + birlik (twenty-one). 0 telefon raqamda — oh.

1-mashq — So‘z bilan yozing

1. 3 → ___

2. 8 → ___

3. 11 → ___

4. 12 → ___

5. 20 → ___

6. 100 → ___

Javoblar: 1. three; 2. eight; 3. eleven; 4. twelve; 5. twenty; 6. one hundred.

2-mashq — Raqam bilan yozing

1. thirteen → ___

2. fifteen → ___

3. forty → ___

4. sixty → ___

5. ninety → ___

Javoblar: 1. 13; 2. 15; 3. 40; 4. 60; 5. 90.

3-mashq — -teen yoki -ty?

1. 14 — (fourteen / forty)

2. 30 — (thirteen / thirty)

3. 16 — (sixteen / sixty)

4. 80 — (eighteen / eighty)

5. 19 — (nineteen / ninety)

Javoblar: 1. fourteen; 2. thirty; 3. sixteen; 4. eighty; 5. nineteen.

4-mashq — 21-99 ni yozing

1. 25 → ___

2. 34 → ___

3. 52 → ___

4. 68 → ___

5. 93 → ___

Javoblar: 1. twenty-five; 2. thirty-four; 3. fifty-two; 4. sixty-eight; 5. ninety-three.

5-mashq — Gapni to‘ldiring

1. I am ___ (20) years old.

2. There are ___ (33) books.

3. She has ___ (2) sisters.

4. How many students? — ___ (15).

5. My number is nine-oh-___ (5).

Javoblar: 1. twenty; 2. thirty-three; 3. two; 4. Fifteen; 5. five.

6-mashq — Xatoni toping va tuzating

1. fourty → ___

2. nintey → ___

3. twenty five (chiziqcha?) → ___

4. I have thirty-three books — 33 to‘g‘rimi? (ha/yo‘q)

Javoblar: 1. forty; 2. ninety; 3. twenty-five; 4. ha, to‘g‘ri.
