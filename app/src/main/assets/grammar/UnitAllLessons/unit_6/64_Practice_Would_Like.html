64-AMALIYOT. WOULD LIKE

Muloyim xohish · would like + ot / would like to + fe’l
Would like — xohishni odobli aytish. Undan keyin ot: I’d like some tea. Ish-harakatni xohlashda would like to + fe’l: I’d like to sit. Taklif: Would you like…?

1-mashq — Ot yoki to + fe’l?

1. I would like ___ (a glass of water).

2. She would like ___ (order dinner).

3. They would like ___ (some tea).

4. He would like ___ (learn English).

5. We would like ___ (a table by the window).

Javoblar: 1. a glass of water; 2. to order dinner; 3. some tea; 4. to learn English; 5. a table by the window.

2-mashq — Would like barcha egalar bilan bir xil

1. He (would like / would likes) a coffee.

2. I (would like / would likes) to go home.

3. They (would like / would likes) some soup.

4. Sara (would like / would likes) to sit down.

Javoblar: 1–4. would like.

3-mashq — Qisqa shaklga o‘tkazing

1. I would like → ___

2. You would like → ___

3. He would like → ___

4. They would like → ___

Javoblar: I’d like; you’d like; he’d like; they’d like.

4-mashq — Would you like…? bilan taklif qiling

1. Do‘stingizga choy taklif qiling.

2. Mehmoningizga o‘tirishni taklif qiling.

3. Birovga sendvich taklif qiling.

Namunaviy javoblar: Would you like some tea? Would you like to sit down? Would you like a sandwich?

5-mashq — Taklifga muloyim javob yozing

1. Would you like some water? (ha, qabul qiling)

2. Would you like a coffee? (yo‘q, muloyim rad eting)

3. Would you like to come with us? (bajonidil rozi bo‘ling)

Namunaviy javoblar: 1. Yes, please. 2. No, thank you. 3. I’d love to.

6-mashq — Xatolarni tuzating

1. She would likes a sandwich.

2. I’d like drink some water.

3. Do you would like tea?

4. He would like to going home.

Javoblar: 1. She would like a sandwich. 2. I’d like to drink some water. 3. Would you like tea? 4. He would like to go home.

7-mashq — Kafedagi dialogni to‘ldiring

Server: ___ you like some tea?

Guest: Yes, please. I’d ___ some tea. I’d also like ___ order a sandwich.

Javoblar: Would; like; to.
