63-DARS. BECAUSE / SO

Sabab va natija · Chunki / shuning uchun
Because sababni tushuntiradi: “chunki”. So natijani bildiradi: “shuning uchun”. Ular ikkita fikrni mantiqan bog‘laydi.

1. Because — chunki

Because dan keyin sabab keladi. “Nima uchun?” degan savolga javob beradi.

Natija + because + sabab
I stayed home because I was sick.Men uyda qoldim, chunki kasal edim.
She is happy because it is her birthday.U xursand, chunki bugun uning tug‘ilgan kuni.
We are late because the bus is slow.Biz kechikdik, chunki avtobus sekin.

Because bilan boshlangan sabab gapning boshida ham kelishi mumkin. Bunday holatda sabab tugagan joyga vergul qo‘yamiz.

Because I was sick, I stayed home.
Kasal bo‘lganim uchun men uyda qoldim.

2. So — shuning uchun

So dan oldin sabab, so dan keyin shu sabab yuzaga keltirgan natija keladi.

Sabab, so + natija
I was sick, so I stayed home.Men kasal edim, shuning uchun uyda qoldim.
It is raining, so we are at home.Yomg‘ir yog‘yapti, shuning uchun biz uydamiz.
He was hungry, so he made a sandwich.Uning qorni och edi, shuning uchun sendvich tayyorladi.

3. Bir vaziyatni ikki xil usulda aytamiz

Sabab va natija o‘zgarmaydi, lekin gapdagi tartib o‘zgaradi.

I took a taxi because I was late.Kech qolganim uchun taksiga o‘tirdim.
I was late, so I took a taxi.Kech qoldim, shuning uchun taksiga o‘tirdim.
Because — sababni tanishtiradi.
So — natijani tanishtiradi.

4. Because va So ni birga ishlatish

Boshlang‘ich oddiy gapda bir sabab-natijani aytish uchun ko‘pincha because yoki so dan bittasini tanlaymiz.

I was tired, so I went to bed. ✅
I went to bed because I was tired. ✅
Because I was tired, so I went to bed. ❌
Oddiy gapda because va so ni birga qo‘ymang.

5. Vergul haqida sodda eslatma

Ikki to‘liq fikrni so bilan bog‘laganda yozuvda ko‘pincha so dan oldin vergul qo‘yamiz.

It was cold, so I wore a coat.Sovuq edi, shuning uchun palto kiydim.
I wore a coat because it was cold.Sovuq bo‘lgani uchun palto kiydim.

Ko‘p uchraydigan xatolar

I stayed home so I was sick. ❌
I stayed home because I was sick. ✅ (sabab)
I was sick, so I stayed home. ✅ (natija)
Because it was late, so we left. ❌
Because it was late, we left. ✅

Mashq 1 — Because yoki So?

1. I wore a coat ___ it was cold. (sabab)

2. It was cold, ___ I wore a coat. (natija)

3. She was hungry, ___ she made lunch. (natija)

4. We stayed inside ___ it was raining. (sabab)

Javoblar:
1. because. 2. so. 3. so. 4. because.

Mashq 2 — Ikki gapni birlashtiring

1. He was tired. He went to bed early. (so)

2. I like this café. The food is good. (because)

3. They missed the bus. They walked home. (so)

Namunaviy javoblar:
1. He was tired, so he went to bed early.
2. I like this café because the food is good.
3. They missed the bus, so they walked home.
