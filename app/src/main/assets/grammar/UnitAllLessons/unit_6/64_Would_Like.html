64-DARS. WOULD LIKE

I’d like... · Muloyim tarzda xohish yoki iltimos aytish
Would like biror narsani xohlashni muloyim, odobli tarzda aytadi. Ko‘pincha do‘konda, kafeda yoki iltimos qilganda ishlatiladi. O‘zbekchaga “xohlardim”, “... olsam/ichsam” kabi tarjima qilinadi.

1. Would Like + ot

Biror narsani xohlasak, would like dan keyin ot yoki narsa nomi keladi.

Subject + would like + noun
I would like some tea.Men biroz choy xohlardim.
She would like a sandwich.U sendvich xohlardi.
They would like a table by the window.Ular deraza yonidagi stolni xohlashadi.

2. Would Like + to + fe’l

Biror ishni qilishni xohlasak, would like to dan keyin fe’lning oddiy shakli keladi.

Subject + would like + to + verb
I would like to drink some water.Men biroz suv ichmoqchiman.
He would like to learn English.U ingliz tilini o‘rganishni xohlaydi.
We would like to sit here.Biz bu yerda o‘tirmoqchimiz.
Would like to dan keyin to + oddiy fe’l keladi: would like to go, would like to eat.

3. Would like barcha egalar bilan bir xil

I, you, he, she, it, we, they bilan would o‘zgarmaydi. He/she/it dan keyin ham would like deymiz, would likes emas.

I would like a coffee.Men bir qahva xohlardim.
She would like a coffee.U bir qahva xohlardi.
They would like a coffee.Ular bir qahva xohlashadi.

4. Qisqa shakl: I’d like

I’d — I would ning qisqa yozilishi. Xuddi shunday, you’d = you would, he’d = he would. Kundalik suhbatda qisqa shakl ko‘p ishlatiladi.

I would like a menu.I’d like a menu.
She would like to order.She’d like to order.
They would like some water.They’d like some water.
’d qisqartmasi boshqa gaplarda had ma’nosida ham kelishi mumkin. Ushbu mavzudagi I’d like esa I would like degani.

5. Would you like...? — Taklif qilish

Birovga biror narsa taklif qilganda Would you like...? deymiz. Bu muloyim “xohlaysizmi?” savoli.

Would + subject + like + noun / to + verb?
Would you like some tea?Choy xohlaysizmi?
Would you like a sandwich?Sendvich xohlaysizmi?
Would you like to sit down?O‘tirishni xohlaysizmi?

6. Taklifga javob berish

Would you like some tea?Yes, please. — Ha, iltimos.
Would you like a coffee?No, thank you. — Yo‘q, rahmat.
Would you like to come with us?I’d love to. — Jon deb / Bajonidil.

7. Want va Would Like farqi

Want “xohlamoq” degani, lekin ba’zi vaziyatlarda to‘g‘ridan-to‘g‘ri eshitilishi mumkin. Would like esa muloyimroq.

I want water.Men suv xohlayman. (to‘g‘ridan-to‘g‘ri)
I’d like some water, please.Iltimos, biroz suv olsam.

8. Ko‘p uchraydigan xatolar

I’d like to go. ✅
I’d like go. ❌

She would like tea. ✅
She would likes tea. ❌

Would you like some tea? ✅
Do you would like tea? ❌

Mashq 1 — Ot yoki to + fe’l?

1. I would like ___ (a book).

2. She would like ___ (learn English).

3. They would like ___ (some juice).

4. He would like ___ (order a taxi).

Javoblar:
1. a book. 2. to learn English.
3. some juice. 4. to order a taxi.

Mashq 2 — Muloyim gap tuzing

1. Men biroz choy xohlardim.

2. U o‘tirishni xohlardi.

3. Siz sendvich xohlaysizmi?

4. Sizlar biz bilan kelishni xohlaysizlarmi?

Namunaviy javoblar:
1. I’d like some tea.
2. He/She would like to sit down.
3. Would you like a sandwich?
4. Would you like to come with us?
