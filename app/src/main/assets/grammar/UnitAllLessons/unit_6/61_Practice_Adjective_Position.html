61-AMALIYOT. ADJECTIVE POSITION

a/an/the/my/this + sifat + ot · to be + sifat
Ot birikmasida: aniqlovchi/artikl + sifat + ot: a red car, my new phone. To‘liq gapda sifat am/is/are dan keyin keladi: The car is red. Sifat ot ko‘plik bo‘lsa ham -s olmaydi.

1-mashq — So‘zlarni to‘g‘ri tartiblang

1. house / a / big

2. my / phone / new

3. red / the / car

4. is / the book / interesting

5. are / the flowers / beautiful

Javoblar: 1. a big house; 2. my new phone; 3. the red car; 4. The book is interesting; 5. The flowers are beautiful.

2-mashq — A yoki An?

Artikldan keyingi birinchi so‘zning tovushiga qarang.

1. ___ old house   2. ___ small orange

3. ___ red apple   4. ___ interesting film

Javoblar: 1. an; 2. a; 3. a; 4. an.

3-mashq — Qavsdan to‘g‘ri variantni tanlang

1. (My / Mine) blue bag is here.

2. (This / These) old book is interesting. (bitta)

3. She has (a / an) beautiful dress.

4. They live in (a / an) small house.

5. He is (a / an) honest man. (h aytilmaydi)

Javoblar: 1. My; 2. This; 3. a; 4. a; 5. an.

4-mashq — Ot oldidami yoki To Be dan keyinmi?

1. a beautiful garden (sifat + ot / subject + be + sifat)

2. The garden is beautiful.

3. my old shoes

4. The shoes are old.

Javoblar: 1. sifat + ot birikmasi; 2. subject + be + sifat; 3. sifat + ot birikmasi; 4. subject + be + sifat.

5-mashq — Sifatni ko‘plikka moslang

1. one small dog → two ___ dogs

2. a red apple → three ___ apples

3. The houses are (big / bigs).

4. Those are (new / news) books.

Javoblar: 1. small; 2. red; 3. big; 4. new. Sifatga ko‘plik -s qo‘shilmaydi.

6-mashq — Ikki sifat bilan ot birikmasi tuzing

1. katta, qizil, mashina

2. kichik, qora, mushuk

3. eski, ko‘k, sumka

Namunaviy javoblar: a big red car; a small black cat; an old blue bag.
