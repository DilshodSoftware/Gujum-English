63-AMALIYOT. BECAUSE / SO

Sabab + natija · “chunki” va “shuning uchun”
Because dan keyin sabab keladi: natija + because + sabab. So dan keyin natija keladi: sabab, so + natija. Oddiy gapda because va so ni birga ishlatmang.

1-mashq — Because yoki So?

1. I took a taxi ___ I was late. (sabab)

2. It was cold, ___ we stayed inside. (natija)

3. She is smiling ___ she is happy. (sabab)

4. He missed the bus, ___ he walked to work. (natija)

5. They went to bed early ___ they were tired. (sabab)

Javoblar: 1. because; 2. so; 3. because; 4. so; 5. because.

2-mashq — Sabab va natijani ajrating

1. I was hungry, so I made a sandwich.

2. We stayed home because it was raining.

3. Because she was sick, she didn’t go to work.

Javoblar: 1. Sabab: och edim; natija: sendvich tayyorladim. 2. Sabab: yomg‘ir yog‘ayotgan edi; natija: uyda qoldik. 3. Sabab: kasal edi; natija: ishga bormadi.

3-mashq — Ikki gapni birlashtiring

1. It was cold. I wore a coat. (so)

2. I stayed home. I was tired. (because)

3. The road was wet. We drove slowly. (so)

4. He is happy. It is his birthday. (because)

Namunaviy javoblar:
1. It was cold, so I wore a coat. 2. I stayed home because I was tired.
3. The road was wet, so we drove slowly. 4. He is happy because it is his birthday.

4-mashq — Because bilan gapni boshidan boshlang

1. I took an umbrella because it was raining. → Because…

2. She went to bed because she was tired. → Because…

Javoblar: 1. Because it was raining, I took an umbrella. 2. Because she was tired, she went to bed.

5-mashq — Ortiqcha bog‘lovchini olib tashlang

1. Because I was late, so I ran.

2. Because it was hot, so we drank water.

3. It was late, so we went home. (to‘g‘rimi?)

Javoblar: 1. Because I was late, I ran. / I was late, so I ran. 2. Because it was hot, we drank water. / It was hot, so we drank water. 3. To‘g‘ri.

6-mashq — O‘zingiz sabab-natija gap tuzing

Because bilan bitta, so bilan bitta gap yozing.

Namunaviy javoblar: I am happy because it is sunny. It is sunny, so we are going to the park.
