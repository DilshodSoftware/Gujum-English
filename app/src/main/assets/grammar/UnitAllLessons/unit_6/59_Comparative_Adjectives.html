Comparative adjective ikki odam yoki narsani solishtiradi: kattaroq, tezroq, yaxshiroq. O‘zbekchada “-roq” ma’nosiga yaqin.

1. Qiyoslashda Than

Ikki narsani solishtirganda birinchisining sifatini aytib, keyin than ishlatamiz. Than — “...dan” degani.

A + be + comparative adjective + than + B
A bus is bigger than a car.Avtobus mashinadan kattaroq.
My bag is heavier than your bag.Sumkam sening sumkangdan og‘irroq.
This road is longer than that road.Bu yo‘l anavi yo‘ldan uzunroq.

2. Qisqa sifatlarga -er qo‘shamiz

Ko‘p qisqa sifatlarning oxiriga -er qo‘shamiz.

SifatQiyosiy shaklMa’nosi
talltallerbaland → balandroq
smallsmallerkichik → kichikroq
fastfastertez → tezroq
oldoldereski/yoshi katta → eskirroq/yoshi kattaroq
cheapcheaperarzon → arzonroq

3. Sifat oxiri E bilan tugasa: faqat R

Sifatning oxirida e bo‘lsa, faqat -r qo‘shamiz.

nice → nicerchiroyli → chiroyliroq
large → largerkatta → kattaroq
safe → saferxavfsiz → xavfsizroq

4. Undosh + Y: Y → IER

Sifat undosh harf + y bilan tugasa, y ni i ga o‘zgartirib -er qo‘shamiz.

happy → happierxursand → xursandroq
easy → easieroson → osonroq
busy → busierband → bandroq

5. Qisqa unli + bitta undosh: oxirgi harf ikkilanadi

Ba’zi qisqa sifatlarda oxiridagi undoshni ikki marta yozib, -er qo‘shamiz.

big → biggerkatta → kattaroq
hot → hotterissiq → issiqroq
thin → thinneringichka → ingichkaroq

6. Uzun sifatlar bilan More

Ko‘p bo‘g‘inli uzun sifatlarning oldidan more qo‘yamiz. Bu ham “-roq” ma’nosini beradi.

more + adjective + than
beautiful → more beautifulchiroyli → chiroyliroq
expensive → more expensiveqimmat → qimmatroq
interesting → more interestingqiziqarli → qiziqarliroq
This book is more interesting than that book.Bu kitob anavi kitobdan qiziqarliroq.

8. Bitta sifatga bitta qiyoslash usuli

Qisqa sifatga -er qo‘shamiz yoki uzun sifatdan oldin more ishlatamiz. Ikkalasini birga ishlatmaymiz.

bigger than ✅   more beautiful than ✅
more bigger ❌
beautifuller ❌
more better ❌ → better ✅

Mashq 1 — Qiyosiy shaklni yozing

1. tall → ___   2. nice → ___

3. happy → ___   4. big → ___

5. beautiful → ___   6. good → ___

7. bad → ___

Javoblar:
1. taller. 2. nicer. 3. happier. 4. bigger.
5. more beautiful. 6. better. 7. worse.

Mashq 2 — Than bilan gapni to‘ldiring

1. A bus is ___ (big) than a car.

2. My room is ___ (small) than your room.

3. This test is ___ (easy) than that test.

4. This phone is ___ (expensive) than my old phone.

5. This book is ___ (good) than that book.

Javoblar:
1. bigger. 2. smaller. 3. easier.
4. more expensive. 5. better.
