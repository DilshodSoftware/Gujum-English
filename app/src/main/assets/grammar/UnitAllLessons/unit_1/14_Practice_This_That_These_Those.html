14-AMALIYOT. THIS / THAT / THESE / THOSE

Yaqin yoki uzoq? Bitta yoki ko‘p? · Ko‘rsatish olmoshlari
Ikki savol bering: narsa yaqinmi yoki uzoqmi? Bittami yoki ko‘pmi?
this = yaqin, bitta · that = uzoq, bitta · these = yaqin, ko‘p · those = uzoq, ko‘p.

1-mashq — Vaziyatga mos so‘zni tanlang

Qavsdan this / that / these / those ni tanlang.

1. (This / These) is my pen. (qo‘limda bitta ruchka)

2. (That / Those) are tall trees. (uzoqda bir nechta)

3. (These / This) are my keys. (yonimda bir nechta)

4. (That / Those) is our school. (uzoqda bitta)

5. (This / These) apples are sweet. (yaqin, ko‘p)

6. (Those / That) bird is very small. (uzoqda bitta)

Javoblar: 1. This; 2. Those; 3. These; 4. That; 5. These; 6. That.

2-mashq — Is yoki Are?

Ko‘rsatish so‘ziga mos to be shaklini qo‘ying.

1. This ___ a new phone.

2. Those ___ my cousins.

3. That ___ an old house.

4. These ___ red flowers.

5. This book ___ interesting.

6. Those shoes ___ clean.

Javoblar: 1. is; 2. are; 3. is; 4. are; 5. is; 6. are.

3-mashq — Yaqin / uzoq va birlik / ko‘plik

Har bir ko‘rsatish so‘zini ikkala xususiyat bilan belgilang.

1. this   2. that   3. these   4. those

Tanlovlar: yaqin / uzoq va bitta / ko‘p.

Javoblar: 1. yaqin, bitta; 2. uzoq, bitta; 3. yaqin, ko‘p; 4. uzoq, ko‘p.

4-mashq — Birlik va ko‘plikni moslang

Gaplarni birlikdan ko‘plikka yoki ko‘plikdan birlikka o‘zgartiring. Ko‘rsatish so‘zi va fe’lni ham almashtiring.

1. This is a book. → yaqin, bir nechta

2. That is a chair. → uzoq, bir nechta

3. These are apples. → yaqin, bitta

4. Those are dogs. → uzoq, bitta

Javoblar:
1. These are books. 2. Those are chairs.
3. This is an apple. 4. That is a dog.

5-mashq — To‘g‘ri gapni toping

1. a) These is a bag.   b) This is a bag.

2. a) Those are my friends.   b) That are my friends.

3. a) These books are new.   b) This books are new.

4. a) That is my parents.   b) Those are my parents.

Javoblar: 1. b; 2. a; 3. a; 4. b.

6-mashq — Xatoni tuzating

1. These is my pencils.

2. That are a bird.

3. This are my parents.

4. Those is a bus.

5. These is an orange. (yaqin, bitta)

Javoblar:
1. These are my pencils. 2. That is a bird.
3. These are my parents. 4. Those are buses.
5. This is an orange.

7-mashq — Ko‘rsatib gapiring

Atrofingizdan yaqin bitta narsa, uzoq bitta narsa, yaqin bir nechta narsa va uzoq bir nechta narsani topib, inglizcha ayting.

Namunaviy javoblar:
This is my cup. That is a door. These are my books. Those are cars.
