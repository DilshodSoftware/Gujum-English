14-DARS. DEMONSTRATIVES

This / That / These / Those · Ko‘rsatish olmoshlari

Biror odam yoki narsani ko‘rsatib, “bu”, “u”, “bular” yoki “ular” demoqchi bo‘lsak, ingliz tilida this, that, these, those so‘zlaridan foydalanamiz.

Ikki savolni eslab qoling:
1. Narsa yaqinmi yoki uzoqmi?
2. Bittami yoki ko‘pmi?

1. To‘rtta ko‘rsatish so‘zi

So‘zMasofaSoniMa’nosi
thisyaqinbittabu
thatuzoqbittau / o‘sha
theseyaqinko‘pbular
thoseuzoqko‘pular / o‘shalar
Yaqin: this / these · Uzoq: that / those
Yaqin va uzoq qat’iy o‘lchov emas: gapiruvchi uchun yaqin turgan narsaga this/these, uzoqdagi narsaga that/those deydi. Gapirayotganda narsani qo‘l bilan ko‘rsatib mashq qiling.

2. This — yaqin va bitta

This yonimizdagi yoki qo‘limizdagi bitta odam yoki narsa uchun ishlatiladi.

This is a book.Bu kitob.
This is my pen.Bu mening ruchkam.
This apple is red.Bu olma qizil.
this + bitta narsa

3. That — uzoq va bitta

That bizdan uzoqroqda turgan bitta odam yoki narsa uchun ishlatiladi.

That is a house.U uy. / Anavi uy.
That is my teacher.U mening o‘qituvchim.
That car is blue.Anavi mashina ko‘k.
that + uzoqdagi bitta narsa

4. These — yaqin va ko‘p

These yonimizdagi ikki yoki undan ko‘p odam yoki narsalar uchun ishlatiladi.

These are books.Bular kitoblar.
These are my keys.Bular mening kalitlarim.
These apples are red.Bu olmalar qizil.
these + yaqin ko‘plikdagi narsalar

5. Those — uzoq va ko‘p

Those bizdan uzoqroqda turgan ikki yoki undan ko‘p odam yoki narsalar uchun ishlatiladi.

Those are birds.Ular qushlar. / Anavilar qushlar.
Those are tall trees.Anavilar baland daraxtlar.
Those houses are new.Anavi uylar yangi.
those + uzoqdagi ko‘plikdagi narsalar

6. This is / That is, These are / Those are

Gapda to be fe’li ham o‘zgaradi: bitta narsa bilan is, ko‘p narsalar bilan are ishlatiladi.

YaqinUzoq
This is a bag.That is a bag.
These are bags.Those are bags.
This / That + is (bitta)
These / Those + are (ko‘p)

7. Ot oldidan yoki o‘zi

Ko‘rsatish so‘zi ot oldidan kelishi mumkin. Ba’zan esa otni takrorlamaslik uchun o‘zi ishlatiladi.

This book is new.Bu kitob yangi.
This is new.Bu yangi.
Those dogs are big.Anavi itlar katta.
Those are big.Anavilar katta.
Ko‘rsatish so‘zidan keyin birlik ot kelsa, odatda a/an qo‘ymaymiz: this a book emas, this book deymiz.

8. So‘roq gaplar

Savol berishda is yoki are gap boshiga chiqadi.

Is this your bag?Bu sizning sumkangizmi?
Is that a bus?Anavi avtobusmi?
Are these your books?Bular sizning kitoblaringizmi?
Are those birds?Anavilar qushlarmi?
Is this / that ...? — bitta narsa haqida
Are these / those ...? — ko‘p narsa haqida

9. Ko‘p uchraydigan xatolar

This are my books. ❌
These are my books. ✅

Those is a house. ❌
That is a house. ✅

These book is new. ❌
This book is new. ✅ (bitta)
These books are new. ✅ (ko‘p)

This a pen. ❌
This is a pen. ✅ / This pen is new. ✅

Mashq 1 — To‘g‘ri so‘zni tanlang

Qavs ichidan mos javobni tanlang.

1. (This / These) is my pencil. (bitta, yaqin)

2. (That / Those) are my friends. (ko‘p, uzoq)

3. (This / These) apples are green. (ko‘p, yaqin)

4. (That / Those) is a school. (bitta, uzoq)

5. (This / These) are my shoes. (ko‘p, yaqin)

6. (That / Those) cat is small. (bitta, uzoq)

Javoblar:
1. This   2. Those   3. These
4. That   5. These   6. That

Mashq 2 — Is yoki Are?

1. This ___ my book.

2. Those ___ tall buildings.

3. ___ these your keys?

4. ___ that your brother?

5. These ___ red apples.

Javoblar:
1. is   2. are   3. Are
4. Is   5. are

Mashq 3 — O‘zbekchadan inglizchaga

Avval narsa yaqinmi/uzoqmi va bittami/ko‘pmi, shuni aniqlang.

1. Bu ruchka. (bitta, yaqin)

2. Anavi uy katta. (bitta, uzoq)

3. Bular kitoblar. (ko‘p, yaqin)

4. Anavi qushlar kichkina. (ko‘p, uzoq)

Javoblar:
1. This is a pen. 2. That house is big.
3. These are books. 4. Those birds are small.

Eng qisqa xulosa

This — yaqin, bitta: This is a cup.

That — uzoq, bitta: That is a cup.

These — yaqin, ko‘p: These are cups.

Those — uzoq, ko‘p: Those are cups.

This / That + is · These / Those + are
