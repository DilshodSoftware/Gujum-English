18-AMALIYOT. POSSESSIVE PRONOUNS

Mine / Yours / His / Hers / Ours / Theirs · “Meniki, sizniki...”
Farqini eslang: my/your/her + ot: my book. Mine/yours/hers otning o‘rnida, mustaqil keladi: The book is mine. Egani so‘rash uchun Whose? deyiladi.

1-mashq — To‘g‘ri egalik shaklini tanlang

1. This is (my / mine) pencil.

2. The pencil is (my / mine).

3. Is that (your / yours) coat?

4. That coat is (your / yours).

5. These are (their / theirs) shoes.

6. These shoes are (their / theirs).

7. The red bag is (her / hers).

Javoblar: 1. my; 2. mine; 3. your; 4. yours; 5. their; 6. theirs; 7. hers.

2-mashq — Egasiga mos egalik olmoshini yozing

1. I own this book. It is ___.

2. You own this seat. It is ___.

3. He owns this bicycle. It is ___.

4. She owns this phone. It is ___.

5. We own this classroom. It is ___.

6. They own these bags. They are ___.

Javoblar: 1. mine; 2. yours; 3. his; 4. hers; 5. ours; 6. theirs.

3-mashq — Ikki gapni takrorlamasdan birlashtiring

Ikkinchi gapda takrorlangan ot o‘rniga egalik olmoshini qo‘ying.

1. This is my pen. That is your pen.

2. This is her bag. That is his bag.

3. These are our books. Those are their books.

Javoblar:
1. This is my pen. That is yours.
2. This is her bag. That is his.
3. These are our books. Those are theirs.

4-mashq — Whose savollariga javob bering

1. Whose book is this? (I)

2. Whose phone is that? (she)

3. Whose bags are these? (they)

4. Whose classroom is this? (we)

Javoblar:
1. It is mine. 2. It is hers. 3. They are theirs.
4. It is ours.

5-mashq — Adjective yoki pronoun?

Bo‘sh joyda ot bor yoki yo‘qligiga qarab qavsdagi juftlikdan tanlang.

1. This is ___ (our / ours) house.

2. This house is ___ (our / ours).

3. ___ (Her / Hers) name is Malika.

4. The blue notebook is ___ (his / he).

5. Are these ___ (their / theirs) keys?

Javoblar: 1. our; 2. ours; 3. Her; 4. his; 5. their.

6-mashq — Xatoni tuzating

1. This is mine book.

2. The red bicycle is her.

3. Is this bag your’s?

4. That classroom is their.

5. The coat is my.

Javoblar:
1. This is my book. 2. The red bicycle is hers.
3. Is this bag yours? 4. That classroom is theirs.
5. The coat is mine.

7-mashq — Mini-dialog

A: Is this your notebook?

B: No, it isn’t ___. It’s Sara’s. It’s ___.

A: And is that our classroom?

B: Yes, it’s ___.

Javoblar: mine, hers, ours.
