19-AMALIYOT. BASIC SENTENCE STRUCTURE

Subject + Verb + (Object) · Ega + Fe’l + (To‘ldiruvchi)
Gapni yig‘ing: avval kim/nima? (Subject), keyin nima qiladi? (Verb), so‘ng kerak bo‘lsa kimni/nimani? (Object). Object ko‘pincha fe’ldan keyin keladi: I read a book.

1-mashq — Gap bo‘laklarini ajrating

Har bir gapdan Subject, Verb va bo‘lsa Objectni toping.

1. The boy eats an apple.

2. We play football.

3. Birds fly.

4. My mother reads a story.

5. They see the teacher.

Javoblar:
1. Subject: the boy; Verb: eats; Object: an apple.
2. We; play; football. 3. Birds; fly; object yo‘q.
4. My mother; reads; a story. 5. They; see; the teacher.

2-mashq — So‘zlarni to‘g‘ri tartiblang

1. apples / eat / I

2. a book / reads / Sara

3. the dog / they / see

4. music / likes / my brother

5. sleep / the babies

6. helps / us / our teacher

Javoblar:
1. I eat apples. 2. Sara reads a book. 3. They see the dog.
4. My brother likes music. 5. The babies sleep. 6. Our teacher helps us.

3-mashq — Subjectmi yoki Objectmi?

Qalin so‘z gapda ishni bajaryaptimi (Subject) yoki harakat unga qaratilyaptimi (Object)?

1. She knows me.

2. I know him.

3. They help us.

4. We see them.

5. My father calls Ali.

6. Sara likes her.

Javoblar: 1. Subject; 2. Object; 3. Subject; 4. Object; 5. Subject; 6. Object.

4-mashq — Object olmoshini tanlang

1. I see (he / him).

2. (They / Them) know my sister.

3. The teacher helps (we / us).

4. (She / Her) likes Tom.

5. We visit (they / them).

6. Ali calls (I / me).

Javoblar: 1. him; 2. They; 3. us; 4. She; 5. them; 6. me.

5-mashq — Kerak bo‘lsa Object qo‘shing

Gapning ma’nosi tugallangan bo‘lsa, “object yo‘q” deb yozing. Aks holda berilgan so‘zlardan object qo‘shing.

1. Birds fly. (object kerakmi?)

2. I read ___. (a magazine)

3. The baby sleeps. (object kerakmi?)

4. We like ___. (our school)

Javoblar: 1. Object kerak emas; gap tugallangan. 2. a magazine. 3. Object kerak emas. 4. our school.

6-mashq — Gap tuzish poyezdi

Berilgan qismlardan Subject + Verb + Object tartibida gap tuzing. Ba’zi gaplarda object yo‘q.

1. Subject: The children · Verb: watch · Object: a film

2. Subject: My friend · Verb: likes · Object: chocolate

3. Subject: Cats · Verb: sleep · Object: —

4. Subject: We · Verb: visit · Object: our grandmother

Javoblar:
1. The children watch a film. 2. My friend likes chocolate.
3. Cats sleep. 4. We visit our grandmother.

7-mashq — Xatoni tuzating

1. She the book reads.

2. Likes Ali music.

3. Him sees I.

4. They the teacher help.

Javoblar:
1. She reads the book. 2. Ali likes music.
3. I see him. 4. They help the teacher.

8-mashq — O‘zingiz 3 ta gap tuzing

Bitta gapda odam, bitta gapda narsa Subject bo‘lsin. Uchinchi gapda Object olmoshi ishlating.

Namunaviy javoblar:
My sister reads a book. The dog likes milk. I know her.
Oxirgi tekshiruv: inglizcha darak gapda Subject odatda boshida turadi. Object bo‘lsa, fe’ldan keyin keladi. Ba’zi fe’llar bilan object kerak bo‘lmasligi mumkin.
