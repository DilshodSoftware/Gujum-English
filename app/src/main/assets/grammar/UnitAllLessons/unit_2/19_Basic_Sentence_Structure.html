Bu dars kim uchun?
Gap tuzishni endi boshlayotganlar uchun. Inglizcha gapda so‘zlar ma’lum tartibda turadi. Avval gapni uch savolga ajratishni o‘rganamiz: kim? — nima qiladi? — kimni/nimani?

1. Oddiy inglizcha gap qanday tuziladi?

Harakatni bildiradigan ko‘p oddiy gaplarning tartibi quyidagicha:

Subject + Verb + Object
SUBJECT
Kim? Nima?
VERB
Nima qiladi?
OBJECT
Kimni? Nimani?
Ba’zi misollarda fe’l oxirida -s harfini ko‘rasiz: she likes. Hozir gapdagi bo‘laklar tartibiga e’tibor bering; fe’lning oxiri ega bilan qanday o‘zgarishini 20-darsda batafsil o‘rganamiz.

Buni uch bo‘lakli poyezddek tasavvur qiling: birinchi bo‘lak — ishni qiluvchi, ikkinchisi — harakat, uchinchisi — harakat qaratilgan odam yoki narsa.

2. Subject — ega

Subject gapda ishni bajaradigan odam yoki narsadir. O‘zbek tilida “kim?” yoki “nima?” deb so‘rab topamiz. Subject ot yoki olmosh bo‘lishi mumkin.

I read books.Men kitob o‘qiyman. (subject = I)
Ali plays football.Ali futbol o‘ynaydi. (subject = Ali)
The dog likes milk.It sutni yoqtiradi. (subject = the dog)
My sister reads.Opam / singlim o‘qiydi. (subject = my sister)

Ingliz tilidagi oddiy darak gapda subject odatda gap boshida keladi.

3. Verb — fe’l

Verb ish-harakat yoki holatni bildiradi. “Nima qiladi?” deb so‘rab topishga urinib ko‘ring.

4. Object — to‘ldiruvchi

Object — harakat kimga yoki nimaga qaratilganini ko‘rsatadi. Odatda fe’ldan keyin keladi.

I read a book.Men kitob o‘qiyman. Nimani? — kitob.
She likes music.U musiqani yoqtiradi. Nimani? — musiqani.
They see the teacher.Ular o‘qituvchini ko‘radi. Kimni? — o‘qituvchini.
Object har doim “narsa” bo‘lavermaydi. Odam ham object bo‘lishi mumkin: I see Ali. — Men Alini ko‘ryapman.

5. Gapni ranglar bilan ajratamiz

Tom reads a book.
Tom — Subject: kim? — Tom.
reads — Verb: nima qiladi? — o‘qiydi.
a book — Object: nimani? — kitobni.

Yana bir misol:

My sister likes chocolate.
My sister = Subject · likes = Verb · chocolate = Object

6. Ingliz va o‘zbek tilidagi tartib

O‘zbek tilida fe’l ko‘pincha gap oxirida keladi: “Men olma yeyman.” Ingliz tilida fe’l egadan keyin, object esa fe’ldan keyin keladi.

I → eat → applesMen → olma → yeyman
Subject → Verb → ObjectEga → To‘ldiruvchi → Fe’l
She likes tea. ✅
She tea likes. ❌
Ingliz tilida objectni fe’ldan oldin qo‘ymaymiz.

7. Object har doim ham bo‘lavermaydi

Ba’zi fe’llar object talab qilmaydi. Gap “kim nima qildi?” degan ma’noni to‘liq bersa, object qo‘shish shart emas.

Birds fly.Qushlar uchadi. (object yo‘q)
The baby sleeps.Chaqaloq uxlaydi. (object yo‘q)
Birds eat seeds.Qushlar urug‘ yeydi. (object = seeds)
Subject + Verb (+ Object)

Gap boshida ishni bajaruvchi subject, fe’ldan keyin esa object keladi.

9. Gap tuzishni qadam-baqadam mashq qilamiz

1-qadam: Kim yoki nima? — ega toping.
2-qadam: Nima qiladi? — fe’l tanlang.
3-qadam: Kimni yoki nimani? — kerak bo‘lsa object qo‘shing.
Kim? INima qilaman? read
Nimani? a bookTayyor gap: I read a book.

10. To be bilan hamma gap SVO bo‘lavermaydi

Bu darsdagi Subject + Verb + Object qolipi harakat fe’llari uchun. To be bilan “Men o‘quvchiman” kabi gaplarda keyingi qism object emas, egani tanishtiradi yoki tasvirlaydi.

I am a student.Subject + to be + kim/nima ekanligi.
She is happy.Subject + to be + qandayligi.
I read a book.Subject + harakat fe’li + Object.

Mashq 1 — Subject, Verb va Objectni toping

1. Sam plays football.

2. We like apples.

3. The baby sleeps.

4. They watch a film.

5. My mother reads a book.

Javoblar:
1. Subject Sam; Verb plays; Object football.
2. We; like; apples. 3. The baby; sleeps; object yo‘q.
4. They; watch; a film. 5. My mother; reads; a book.

Mashq 2 — So‘zlarni to‘g‘ri tartibga qo‘ying

1. reads / Amina / books

2. the dog / likes / water

3. football / play / We

4. sleeps / My brother

5. music / They / like

Javoblar:
1. Amina reads books. 2. The dog likes water.
3. We play football. 4. My brother sleeps.
5. They like music.

Mashq 3 — O‘zbekchadan inglizchaga

So‘zlardan foydalaning: I, she, reads, likes, books, tea.

1. Men kitob o‘qiyman.

2. U choyni yoqtiradi.

Javoblar:
1. I read a book / I read books. 2. She likes tea.

Subject — kim/nima ish qiladi.

Verb — nima qiladi.

Object — harakat kimga/nimaga qaratilgan.

Asosiy tartib: Subject + Verb + Object; ba’zi gaplarda Object bo‘lmaydi.
